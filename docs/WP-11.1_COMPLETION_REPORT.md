## 5. Architecture changes

### Before

```text
loop: lid → ultrasonic_schedulerTick → Approach | Waste → led → wifi/http
```

### After

```text
loop: lid → runApproachMeasurementIfDue → [approach] log → led → wifi/http
```

Approach schedule rules:

1. Skip if `now < s_quietUntilMs` (`CONFIG_ULTRASONIC_QUIET_MS` after each pulse).
2. Skip if `now < s_nextApproachMs`.
3. Else `approachSensorRunMeasurement()`, advance next sample by `CONFIG_APPROACH_SAMPLE_MS`.

Loop order preserved: **`lidControlUpdate` before** approach measurement (same one-sample latency as pre-WP-11.1).
