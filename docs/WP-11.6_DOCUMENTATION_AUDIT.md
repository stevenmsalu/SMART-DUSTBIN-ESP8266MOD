## 3. Current documentation assessment

| Area | Implemented behaviour |
|------|------------------------|
| **Sensors** | Single HC-SR04 (approach) on D1 TRIG / D2 ECHO |

| **White LED** | D0 / GPIO16; **on when lid open** (`white_indicator`) |
| **Removed from firmware** | Waste sensor (D5/D6), fill %, yellow LED, buzzer drive, `smart-dustbin-programme/` sketch |
| **Network** | Wi-Fi via `wifi_config.h`; HTTP port **80** |

| **Dashboard** | Embedded in `src/dashboard_page.cpp` (WP-11.4 UX) |
| **Libraries** | ESP8266 core: `Servo`, `ESP8266WiFi`, `ESP8266WebServer` (no extra install beyond core) |

**Active `config.h` defaults (provisional — not logged as Accepted in CALIBRATION_LOG):**

| Constant | Value |
|----------|--------|
| `CONFIG_SERIAL_BAUD` | 115200 |
| `CONFIG_HEARTBEAT_MS` | 5000 |
| `CONFIG_APPROACH_DETECT_CM` / `CLEAR_CM` | 50 / 55 |
| `CONFIG_APPROACH_SAMPLE_MS` | 100 |

| `CONFIG_SERVO_ANGLE_CLOSED` / `OPEN` | 30 / 120 |
| `CONFIG_LID_CLOSE_DELAY_MS` | 2000 |
