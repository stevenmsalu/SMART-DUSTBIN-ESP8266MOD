## 5. Include-path verification

ESP8266 Arduino core **3.1.2** (arduino-cli) behaviour observed:

- `.cpp` under `src/` is compiled from `sketch/src/` but **does not** receive `-I` for the sketch root.
- `.ino` preprocessing does **not** resolve bare `"module.h"` when the header lives only under `src/`.

**Minimal structural include updates (no logic):**

| Location | Change |
|----------|--------|
| `SmartDustbin.ino` | Module includes → `#include "src/…"`; `config.h` stays `#include "config.h"` |
| `src/*.cpp` referencing root config | `config.h` → `../config.h` (`approach_sensor`, `lid_control`, `http_api`, `wifi_manager`) |
| `src/*.cpp` referencing `pins.h` | → `../pins.h` (`approach_sensor`, `gpio_init`, `lid_control`, `white_indicator`) |
| `src/wifi_manager.cpp` | `wifi_config.h` → `../wifi_config.h` |

**Intra-`src/` includes** (e.g. `"approach_sensor.h"`, `"lid_control.h"`) unchanged.

## 10. Opening the project in Arduino IDE

1. **File → Open** → select folder `SmartDustbin` (must contain `SmartDustbin.ino`).

3. Ensure local **`wifi_config.h`** exists beside `wifi_config.h.example` (copy template if missing).
4. **Sketch → Verify/Compile** (same sources as CLI).
